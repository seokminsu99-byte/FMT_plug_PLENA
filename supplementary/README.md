# Supporting files

- [`Supporting_Information.docx`](Supporting_Information.docx) contains the
  Supporting Information text and Figures S1-S3 for the accompanying
  *Hydrological Processes* manuscript.
- [`Data_S2.xlsx`](Data_S2.xlsx) contains catchment-level beta estimates,
  candidate-specific NSE summaries, beta-class counts, GIS-derived catchment
  areas, annual and derived inundation metrics, and formula-linked checks for
  manuscript Tables 4 and 5.

Municipal drainage-network and catchment GIS files are not redistributed
because their access and reuse are controlled by the Seoul Metropolitan
Government.
